# سفارش کیک قنادی

**[باز کردن اپ (لینک زنده)](https://mikhak-online.github.io/sefarsh-cake/)**

اپ سفارش کیک قنادی: مشتری در یک فرم ساده نوع کیک، اندازه، طعم، متن روی کیک و روز تحویل را انتخاب می‌کند و سفارش را ثبت می‌کند؛ قنادی همه‌ی سفارش‌ها را یکجا، مرتب، در یک لیست می‌بیند.

روی گوشی با Add to Home Screen نصب می‌شود (PWA) و آفلاین هم کار می‌کند. سفارش‌ها و منو فقط در حافظه‌ی همان گوشی می‌مانند؛ سرور ندارد.
